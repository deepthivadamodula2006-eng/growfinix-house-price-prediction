# Growfinix House Price Prediction

## Project Overview

This project predicts house prices using machine learning techniques.

## Project Structure

- `data/` — Dataset files
- `notebooks/` — Jupyter Notebook containing the analysis and model
- `outputs/` — Generated prediction/submission file

## Dataset

The project uses training and test datasets for building and evaluating the house price prediction model.

## Technologies Used

- Python
- Pandas
- NumPy
- Scikit-learn
- Jupyter Notebook
- Matplotlib
- Seaborn

## Output

The final predictions are available in:

`outputs/submission.csv`
